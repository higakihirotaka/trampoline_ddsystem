Googleアカウントの追加（管理者の追加）

仕組み

管理者ログインには Google アカウントを使用します。 ログイン時に Firestore の admins コレクションへ そのアカウントの UID が登録されているかを確認し、 登録済みの場合のみ管理者として認可されます。

ℹ️　UID とは、Firebase が各 Google アカウントに割り当てる固有のIDです。 Firebase コンソールの Authentication → Users で確認できます。

追加手順（詳細）

  1. 1
    追加したい人に一度ログインを試みてもらう
    以下のURLにアクセスし、「Googleでログイン」を押してGoogleアカウントでサインインしてもらいます。
    https://travaults-system.web.app/admin_login.html
    「管理者権限がありません。」と表示されますが、これは正常です。 この操作によってそのアカウントが Firebase Authentication に登録され、 UID が発行されます。
  2. 2
    Firebase Console を開く
    console.firebase.google.com にアクセスし、プロジェクト trampoline-dd-test を選択します。
  3. 3
    UID を確認する
    左メニューの Authentication → Users タブを開きます。
    一覧からステップ1でログインを試みたアカウントを探し、 ユーザーUID 列の値をコピーします。
    （例: aBcD1234EfGh5678IjKl のような英数字の文字列）
  4. 4
    Firestore の admins コレクションにドキュメントを追加する
    左メニューの Firestore Database を開き、データタブを選択します。
    admins コレクションをクリックし、 「＋ ドキュメントを追加」 をクリックします。
    admins　→　＋ ドキュメントを追加
    ドキュメントID の欄に、コピーした UID をそのまま貼り付けます。
    フィールドは空でも動作しますが、管理のため name（文字列）に氏名を入れておくと便利です。

    入力例：
    ドキュメントID: aBcD1234EfGh5678IjKl
    フィールド: name = "山田 太郎"
    最後に 「保存」 をクリックします。
  5. 5
    追加した人にログインし直してもらう
    再度 admin_login.html から Google でログインすると、 管理者として認可され管理画面（admin_index.html）に入れるようになります。
⚠️　admins コレクションへの追加・変更は、 Firebase Console の操作権限（プロジェクトオーナーまたは編集者）を持つアカウントのみ行えます。 コンソールへのアクセス権限は Google Cloud IAM で別途管理してください。

権限の削除

管理者権限を失効させるには、 Firestore の admins コレクションから対象の UID のドキュメントを削除します。 次回ログイン時から管理者として認可されなくなります。

✅　Firebase Authentication 側のアカウント（Users）を削除しなくても、 admins コレクションからドキュメントを消すだけで権限は失効します。
