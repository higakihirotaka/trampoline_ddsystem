Trampoline Scoring System — 運用マニュアル（管理者向け）

Googleアカウントの追加（管理者の追加）

仕組み

管理者ログインには Google アカウントを使用します。 ログイン時に Firestore の admins コレクションへ そのアカウントの UID が登録されているかを確認し、 登録済みの場合のみ管理者として認可されます。

ℹ️　UID とは Firebase が各 Google アカウントに割り当てる固有IDです。 追加される人には専用ページでUID取得・送付を依頼します（次の手順）。

① 追加したい人に専用URLを送る

以下の URL を LINEやメールなどで相手に送ってください。
相手はそのページを開き、Googleでログインするだけで自分のUIDを確認・コピーできます。

https://travaults-system.web.app/request_access.html

相手が操作を完了すると、メールアドレス と UID を送ってくれます。
それを受け取ったら次のステップへ進みます。

② 受け取った UID を Firestore に追加する

  1. 1
    Firebase Console を開く
    console.firebase.google.com にアクセスし、プロジェクト trampoline-dd-test を選択します。
  2. 2
    Firestore Database → admins コレクションを開く
    左メニューの Firestore Database → データタブを開き、 admins コレクションを選択します。
    Firestore Database → データ → admins
  3. 3
    ドキュメントを追加する
    「＋ ドキュメントを追加」 をクリックし、 ドキュメントID の欄に受け取った UID を貼り付けます。
    管理のため name（文字列型）フィールドに氏名を入れておくと便利です。
    ドキュメントID: <受け取ったUID>
    フィールド（任意）: name = "氏名"
    最後に 「保存」 をクリックします。
⚠️　Firestore Console の操作には Firebase プロジェクトの編集権限が必要です。

③ 相手に完了を伝える

Firestore への追加が完了したら、相手に連絡してください。
以下のURLからログインできるようになります。

https://travaults-system.web.app/admin_login.html

権限の削除

管理者権限を失効させるには、Firestore の admins コレクションから 対象の UID のドキュメントを削除します。 次回ログイン時から管理者として認可されなくなります。

✅　Firebase Authentication 側のアカウント（Users）を削除しなくても、 admins コレクションからドキュメントを消すだけで権限は失効します。
