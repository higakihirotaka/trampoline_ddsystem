Trampoline Scoring System
動きを見てみる

選手が提出する競技カード、大会当日に使う3つの画面、D（難度）の計算ページです。すべてダミーデータで動き、どこにも接続せず、何も保存しません。

会場ディスプレイ

得点表示

会場の大型ディスプレイに映る画面です。得点が確定すると、内訳とともに演技の結果が表示され、そのあと順位表に切り替わります。

この画面: 個人 Aクラス 男子 決勝。中田選手が確定した直後（順位1位）から始まります。
開く → 選手

競技カード提出

選手が、これから行う演技構成（10本の技）を自分のスマートフォンから入力して提出します。技を選ぶと、難度（D）がその場で計算されます。

この画面: 中田選手の決勝のカード（空欄）。ふりがなと10本の技を入れて「提出」できます（どこにも登録されません）。「予選演技をコピーする」で、技をまとめて入れることもできます。
開く → D審判

D審判画面

選手が申告した演技構成（技）を確認し、実際に行われた技を確定します。難度（D）が自動で計算されます。

この画面: 個人 Aクラス 男子 決勝の、次の選手（番所選手）。「確定・保存」を押せます（修正も可能）。
開く → CJP（主審）

CJP画面

E審判の減点、D、ToF・HD、ペナルティをまとめて、得点を確定する画面です。確定すると、会場ディスプレイに結果が出ます。

この画面: 個人 Aクラス 男子 決勝の、中田選手の実データ。「修正」「確定&表示」などを試せます（ほかの画面とは連動しません）。
開く → 計算ツール

D計算用

技を選ぶだけで、基礎点とボーナス点、Total DD を計算します。CSVでの保存や、日本語・英語の切り替えにも対応しています。

技名の欄に入力してEnterで次の行へ。右上の「日本語 | EN」で表示言語を切り替えられます。

このデモについて
  • データは、実際の大会（第61回全日本学生トランポリン競技選手権大会）の個人Aクラス男子の決勝を元にしたダミーです。英語表示では、選手名はふりがなからローマ字にし、大学名は各大学の英語表記にしています。
  • 各画面は独立して動きます。ある画面での操作は、ほかの画面には反映されません。
  • 操作した内容は、ページを再読み込みする（言語を切り替える）と元に戻ります。
  • 会場ディスプレイは横長（16:9）の画面用です。パソコンの広い画面で開くと、本来の見た目になります。
